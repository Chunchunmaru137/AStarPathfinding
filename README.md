# AStarPathfinding
# Реализация поиска пути A* (A-Star) на C#

Простая консольная реализация алгоритма A* для поиска кратчайшего пути на сетке. Написал для себя, чтобы разобраться, как работают эвристики и оптимизация поиска.

### Как это работает
Сетка задается матрицей, где `0` — свободный проход, а `1` — стена. 
Для оценки стоимости пути используется Манхэттенское расстояние. В качестве открытого списка пока используется обычный List, в будущем планирую переписать на бинарную кучу для оптимизации.

### Запуск
Проект сделан на .NET 8. Запустить можно стандартно через CLI:
dotnet run
